## What is TaskSocial?

TaskSocial is a social accountability application where users can create tasks, track their progress, and view a shared task feed.

The REST API supports account registration, login, task creation, retrieving a user's tasks, viewing the shared feed, updating tasks, and deleting tasks.

## How authentication works

TaskSocial uses a JWT stored in an HTTP-only cookie named `tokenName`.

After logging in, your HTTP client must retain and send this cookie when calling protected endpoints. Task updates and deletions also require the authenticated user to own the target task.

## API base URL

The production API is hosted on Render:

```text
https://tasksocial-p2cw.onrender.com
```

All API endpoints use the `/api/v1` path prefix. For example, the login endpoint is:

```text
POST /api/v1/auth/login
```
